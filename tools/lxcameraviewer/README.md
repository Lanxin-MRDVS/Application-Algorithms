# LxCameraViewer

[Documentation Home](../../README.md) / [Tools](../README.md) / LxCameraViewer

LxCameraViewer is the shared MRDVS camera setup and diagnostic application. Use it to discover cameras, configure networking and parameters, inspect depth images or point clouds, and verify camera data before deploying an application algorithm.
