# Volume Measurement

[Documentation Home](../README.md) / Volume Measurement

MRDVS 3D volume measurement uses depth cameras and point-cloud processing to measure object dimensions and calculate volume. It supports logistics and industrial use cases such as packages, pallets, luggage, cargo, and material piles.

**[View the MRDVS 3D Volume Measurement solution](https://mrdvs.com/3d-volume-measurement/)**

## Capabilities

- Measures single or multiple objects within the camera field of view.
- Uses 3D shape and dimension data rather than length and width alone.
- Supports applications in warehousing, logistics, manufacturing, and material handling.
