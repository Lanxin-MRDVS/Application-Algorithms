# Depalletizing

[Documentation Home](../../README.md) / [Applications](../README.md) / Depalletizing

Depalletizing is an AW3 application for vision-guided soft-bag and carton unstacking. AW3 manages device connections, camera configuration, calibration, algorithm execution, result visualization, and task templates.
