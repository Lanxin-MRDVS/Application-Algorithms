# Volume Measurement

[Documentation Home](../../README.md) / [Applications](../README.md) / Volume Measurement

MRDVS 3D volume measurement uses depth cameras and point-cloud processing to measure object dimensions and calculate volume. It supports logistics and industrial applications involving packages, pallets, luggage, cargo, and material piles.

| Status | Value |
| --- | --- |
| Target runtime | AW3 |
| Public application package | No public release yet |
| Product page | [MRDVS 3D Volume Measurement](https://mrdvs.com/3d-volume-measurement/) |

## Capabilities

- Measures single or multiple objects within the camera field of view.
- Uses 3D shape and dimension data rather than length and width alone.
- Supports warehousing, logistics, manufacturing, and material-handling workflows.
