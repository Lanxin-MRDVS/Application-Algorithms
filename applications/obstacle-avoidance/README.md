# Obstacle Avoidance

[Documentation Home](../../README.md) / [Applications](../README.md) / Obstacle Avoidance

Obstacle Avoidance provides camera-side obstacle detection, configurable detection zones, calibration, network communication, and result outputs for mobile robots and forklifts.
