# AW3 Platform

[Documentation Home](../../README.md) / [Platforms](../README.md) / AW3

AW3 is the shared application runtime and delivery platform for MRDVS 3D vision workflows. It manages device connections, configuration, calibration, algorithm execution, result visualization, and task templates.

## Application scope

| Application | AW3 status |
| --- | --- |
| [Depalletizing](../../applications/depalletizing/README.md) | Publicly documented in AW3 3.0.1 |
| [Pallet Docking](../../applications/pallet-docking/README.md) | Target runtime; current public workflow uses PalletPro |
| [Volume Measurement](../../applications/volume-measurement/README.md) | Target runtime; no public AW3 package recorded yet |
| [Slot Monitoring](../../applications/slot-monitoring/README.md) | Target runtime; no public AW3 package recorded yet |
