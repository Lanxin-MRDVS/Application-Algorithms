# Volume Measurement Release Files

[Documentation Home](../../README.md) / [Volume Measurement](../README.md) / Release Files

The public [Software update history](../README.md#software-update-history) is maintained at the bottom of the Volume Measurement product page. This folder stores one immutable `v<version>.md` release note for every published formal software version and standalone update.

Each version note records the applicable documents, formal-version baseline, AW3 compatibility, superseded updates, package filename, size, SHA-256 checksum, upgrade steps, rollback steps, and GitHub Release link.
